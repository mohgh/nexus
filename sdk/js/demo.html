Nexus SDK Demo

Drop-in browser SDK for the Nexus analytics API.

1. Configure

Paste a tenant API key. Mint one with an admin key (the API key sets the tenant — you don't send a tenant id):

curl -X POST localhost:8000/api/v1/admin/api-keys \
  -H "X-API-Key: $ADMIN_KEY" \
  -d '{"scope":"tenant","tenant_id":"<UUID>","name":"demo"}'
